# October 2017 retrospective case: fixed descriptive rules

This case was selected by the author and had already appeared in the Phase 3
historical report. Dates and some counts were therefore already inspected.
This document fixes the presentation calculation, not a preregistered analysis.
No forecasting experiment, statistical significance test or causal effect is estimated.

Anchor the comparison to October 12, 2017, the dated Loudwire/Alternative Nation
coverage, not the later publisher-page date or an unverified recording date.
Reuse the Phase 3 descriptive rule: preceding 28 dates September 14–October 11,
and seven dates beginning October 12 (through October 18), all inclusive UTC days.
Report raw counts, prior mean/median/min/max, following-seven mean and their
ratio. Plot September 14–October 31, retaining every date and a linear count axis.
The observed prior min/max band is descriptive, not a prediction interval.

Podcast directory metadata list October 10; primary original RSS and recording
time have not been recovered. Show that date with a distinct uncertainty label.
Check a 28-day reference ending October 9 (September 12–October 9) because the
main reference includes two days after the listed episode date. Report both
reference calculations; do not choose one to maximize the visual contrast.
Calendar publication dates are not precise UTC timestamps. Compare the observed
peak to prior observed variation, not a Gaussian significance calculation.

Retain both already-used release cases (Dreams Remembered and Sea Above The Sky),
including their opposed descriptive patterns. Their calculations/ledger categories
remain frozen. No event changes eligibility and no event becomes a model feature.
